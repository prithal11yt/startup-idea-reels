# Startup Idea reels

Finished reels from the "Startup Idea" Instagram series by [@thesoloentrepreneur.yt](https://www.instagram.com/thesoloentrepreneur.yt/).

Each reel takes one business plan and turns it into a ~60-second explainer: the idea, the
problem, a product demo, the competitors, the money, and what the plan projects.

The video files live as **release assets** (one release per reel) rather than in git, so the
repository stays small. Captions and build notes live alongside them.

Built with the news-reels Remotion engine.
